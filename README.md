# ServiceHub 📋

ServiceHub is a full-stack task management application designed to help users track, organize, and manage daily tasks and projects efficiently. Built with **Angular** on the frontend and a **C# (.NET)** REST API backend.

---

## 🚀 Live Demo & Links

* **Frontend App:** [https://angular-3-n9hk.onrender.com)
* **Backend API:** Hosted on Render
* **Repository:** [MOHANCHARAN24/ANGULAR](https://github.com/MOHANCHARAN24/ANGULAR)

---

## ✨ Features

* **Task Tracking:** Create, update, organize, and delete daily tasks or project items.
* **Status Updates:** Monitor task progress with status updates driven by backend API endpoints.
* **Responsive UI:** Dynamic and mobile-friendly interface built with Angular components.
* **REST API Integration:** Clean separation of concerns with asynchronous API calls to the C# backend.

---

## 🛠️ Tech Stack

* **Frontend:** Angular, TypeScript, HTML5, CSS3 / SCSS
* **Backend:** C# (.NET / ASP.NET Core REST API)
* **Hosting & Deployment:** Vercel (Frontend), Render (Backend)
